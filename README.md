# 使用 Vercel 反代 midjourney （图文教程）

## 简介

国内只是墙了 vercel 本身的域名，但是自定义域名没有墙，因此做了代理并绑定域名之后就可以用自己的域名在国内直连 midjourney 了。

理论上也可以代理其他被墙的站点。

## 使用方法

- 访问 midjourney 时，将 [https://cdn.discordapp.com](https://cdn.discordapp.com) 换成你的自定义域名，例如


## bak
- https://media.discordapp.net
- https://cdn.discordapp.com
